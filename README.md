# SAHPRA Regula AI Platform — HTML, CSS and JavaScript demo

A responsive, browser-only prototype built with **HTML, CSS and vanilla JavaScript**. It does not need Node.js, a server, a backend, or a database.

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a modern browser (Chrome or Edge recommended).
3. Click **Fill demo credentials**, or use the details below.

Tasks, research briefs, selected plan, and activity may persist in that browser using local storage; they are not shared across devices or users and are not securely stored in a server database.

## Included agents
1. **Research Agent** — regulatory topic research and briefs.
2. **Workflow Agent** — tasks, priorities and progress tracking.
3. **Orchestrator Agent** — coordinates multi-step work plans.

The Agent Studio can generate structured checklists, add recommended actions to workflow tasks, and export a text draft. Other features include document checklist review, multi-agent planning, task management, notifications, analytics, demo administration, profile settings, and a chatbot-style assistant.

## Important limitations
This is an independent prototype and is **not an official SAHPRA service**. It is not connected to a live AI model or verified live regulatory search. Agent output is illustrative, not regulatory advice and not a determination of product status, classification, approval, or compliance. The browser-only document review supports text and Markdown files; it does not upload files or extract PDF/DOCX content. Always verify current requirements against official SAHPRA publications and obtain qualified human review before making regulatory decisions.
